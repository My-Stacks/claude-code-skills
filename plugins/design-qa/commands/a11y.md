Run only the a11y audit against `$1`.

1. Run `bash ${CLAUDE_PLUGIN_ROOT}/bin/run-axe.sh "$1"` — axe-core via `@axe-core/playwright`, which:
   - Loads the page in headless Chromium.
   - Triggers hover and focus states on each interactive element before scanning (catches contrast bugs that only surface on interaction).
   - Runs the scan at mobile (375), tablet (768), and desktop (1440) widths.
   - Runs the scan in light AND dark theme.
   - Outputs JSON to `.claude/design-qa/reports/<timestamp>/axe/`.
2. Run `bash ${CLAUDE_PLUGIN_ROOT}/bin/run-pa11y.sh "$1"` for second-opinion coverage.
3. Combine results. WCAG 2.2 AA is the bar.
4. Suppress any rules listed in `reviewer.json` `excludeRules`. Note suppressions explicitly.
5. Report as severity-ranked markdown:
   - **Blockers:** WCAG-A violations or any contrast failure on visible text.
   - **High:** WCAG-AA violations.
   - **Medium:** Best-practice violations (e.g., missing `<main>` landmark, redundant ARIA).
   - **Nitpicks:** style-of-implementation issues axe flags as "needs review."
6. For each finding include the selector, the rule ID, the impact, and the screenshot showing it.
